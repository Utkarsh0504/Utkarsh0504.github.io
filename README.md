# Utkarsh Singh — Developer Portfolio

A responsive single-page portfolio inspired by the polished structure of Dhruv Baslas's portfolio, but with original design, content, layout, and styling tailored to .NET + Azure engineering.

## Preview locally

- Open `index.html` in any modern web browser; no installation or build step required.
- Or run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish free on GitHub Pages

1. Log in to your own GitHub account (or create one).
2. Create a **public** repository named **Utkarsh0504.github.io** under your connected GitHub account (`Utkarsh0504`).
3. Upload the **contents** of this folder directly into the repository's root so `index.html` is at the root. Include the `assets` and `resume` folders.
4. In repository **Settings → Pages**, under **Build and deployment**, choose **Deploy from a branch**, **main**, and **/(root)**. Save.
5. Your site should become available at `https://utkarsh0504.github.io/` after GitHub finishes its first deployment.
6. Visit the public URL and test navigation, dark/light mode, project expansion, email, and resume download.

If you choose a repository named `portfolio` instead of `Utkarsh0504.github.io`, the published URL is typically `https://Utkarsh0504.github.io/portfolio/`. For that case use **relative** asset paths as this site does.
